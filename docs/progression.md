# 進行フローとアンロック順

憲法は CLAUDE.md 2.5。ここでは全体の流れを書く。
個々のクエストは `data/prices.yaml` と `data/eyes.yaml` から生成する。

## 全体像

    畑を作る → 料理に加工する → 納品して稼ぐ → 鉱物を買う
      → 工業と魔法で省力化する → 畑の規模を上げる
      → 目12種を作る → ポータルフレームを作る → ドラゴン

工業・魔法・農業のどれか1つでは門が開かない。これを崩さない。

## 段階

### 第1段階 — 手作業の農業

プレイヤーはツルハシを持たずに始める。鉱石が湧かないので掘る意味がない。

- 作物を育てて納品し、最初のコインを得る
- ショップで**鉄を買う**。これが経済の起点（憲法 2.2）
- 鉄ツルハシを作り、Mystical Agriculture の Prosperity 鉱石を掘れるようになる

ここで「鉱石は掘るものではなく買うもの」を体で理解させる。
クエストブックで明示する必要がある。

### 第2段階 — 加工と季節

- Farmer's Delight で料理を作り、単価を上げる
- 最初の冬が来る。畑が止まる
- 止まっている間にやることとして、畜産・釣り・工業の入口を提示する

冬が「詰み」ではなく「別のことをする時間」になっているかが、
このmodpackが成立するかどうかの分かれ目になる。

### 第3段階 — 省力化

- Create で植え付け・収穫・調理を自動化する
- Ars Nouveau の使い魔で運搬を任せる
- Agronomic Sourcelink で畑から Source を得る（憲法 2.5）

自動化装置のレシピには農産物・加工食品を要求する（憲法 2.1）。
規模を上げるほど畑も広げることになる構造を維持する。

### 第4段階 — 温室と通年農業

- グリーンハウスガラスで冬でも育てられるようにする
- 高価格に設定する（憲法 2.4）。ここが中盤の主要目標

### 第5段階 — エンドへ

エンド要塞は生成しない（CLAUDE.md 5.2）。自力で門を建てる。

| 必要なもの | 作り方 |
|---|---|
| エンダーアイ ×12種 | Ars Nouveau の Enchanting Apparatus。材料は農業由来の料理 |
| エンドポータルフレーム ×12 | Create の連続組み立て |
| 戦闘装備 | Mystical Agriculture のエッセンス装備 |

**エンダーアイを投げても何も見つからない**状態になる。これは仕様であって
バグではない。クエストブックで先に伝えないと詰んだと誤解される（CLAUDE.md 5.2）。

## 未決定

以下が決まるまで、クエストの具体的な並びは確定しない。

- 12種の目に割り当てる料理チェーン（`data/eyes.yaml` が空の理由）
- 料理納品の時給想定（`data/prices.yaml` が空の理由）
- 鉱石以外の鉄入手経路をどこまで塞ぐか

最後の項目は第1段階の成立に直接効く。村チェスト・鉄ゴーレム・ゾンビドロップ・
ピグリン交易のいずれかが空いていると、「最初の鉄をショップで買う」という
起点が迂回される。詳細は CLAUDE.md 7章。
