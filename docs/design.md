# ゲームデザイン詳細

CLAUDE.md 1章と2章の補足。憲法そのものは CLAUDE.md にあり、
このファイルはそれを変更しない。

## 何を作ろうとしているか

ルーンファクトリー・牧場物語・スターデューバレーの生活感を Minecraft に
持ち込む。ただし生活シミュレーションで終わらせず、エンダードラゴン討伐まで
一本の線で繋ぐ。

「農業をしていたら、いつのまにかドラゴンを倒せる装備になっていた」
という体験を作る。

## 3つの柱の関係

    農業 ── 主役。収入と素材の源
      │
      ├─ 工業（Create）── 農業の作業を減らす道具
      └─ 魔法（Ars Nouveau）── 農業の作業を減らす道具

工業と魔法はそれ自体を目的地にしない（憲法 2.1）。
このため次を守る。

- 自動化装置のレシピは農産物・加工食品を要求する
- 鉱石倍化のような「農業を経由せず資源が増える」経路は入れない
- 工業・魔法の到達点は「畑がもっと広く回せる」ことであって、
  「工業製品そのもの」ではない

## 季節の役割

Serene Seasons を入れる理由は雰囲気ではなく、**リズム**のため（憲法 2.4）。

冬に畑が止まることで、

- 畜産・釣りという別の収入源に触る理由ができる
- 工業と魔法を仕込む時間ができる
- 温室という明確な中期目標ができる

Mystical Agriculture の作物にも季節制限をかける。
かけないと「鉱石農場だけ冬も動く」状態になり、冬が単なる待ち時間になる。

## エンドゲームの設計意図

エンド要塞を消して自力でポータルを建てさせるのは、
**最終目標を農業の延長線上に置く**ため。

- 目12種はすべて別系統の食材チェーンを要求する → 畑の多様性が必要になる
- ポータルフレームは Create の連続組み立て → 工業が必要になる
- 目の生成は Enchanting Apparatus と Source → 魔法と、Source を供給する畑が必要になる

3つ全部やらないと門が開かない。どれか1つに偏った進め方を封じている。

## 意図的に不便にしている点

これらは調整漏れではなく設計なので、勝手に直さない。

| 挙動 | 意図 |
|---|---|
| 鉱石を掘っても何も出ない | 鉱物は買うもの（憲法 2.2） |
| エンダーアイを投げても何も見つからない | 要塞が無い（CLAUDE.md 5.2）。クエストブックで説明する |
| 冬に畑が止まる | 他の要素に時間を割かせる（憲法 2.4） |
| 鉱石倍化ができない | 農業の規模で解くべき問題にする（憲法 2.1） |

いずれもプレイヤーには「詰んだ」と見える瞬間がある。
クエストブックでの説明が無いと、ただのバグとして受け取られる。
